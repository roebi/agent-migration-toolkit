# Process collection meeting - agenda

Department: ____________________
Date: ____________________
Attendees: ____________________

## Agenda

1. Explain goal (5 min) - we are documenting what you do today, not
   deciding what gets automated. Nothing changes as a result of this
   meeting by itself.
2. Walk through the department's processes end to end (30-45 min) -
   use process-collection-form.md, one form per process.
3. Split each process into sub-processes (15 min) - use
   process-split-worksheet.md.
4. Classify automation grade + interface type per sub-process (15 min).
5. Capture open questions and disagreements in decision-log-entry.md -
   do not resolve them in the room, log them for R-CTRL follow-up.

## Ground rule

If a sub-process involves customer or license data, note it explicitly
- it is in scope for the Red Line regardless of automation grade.
